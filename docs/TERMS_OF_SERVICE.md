# Syarat dan Ketentuan BERKAH POS

**Status dokumen: DRAF — perlu pemeriksaan dan persetujuan pengelola sebelum publikasi.**

## 1. Ruang lingkup
BERKAH POS Basic adalah aplikasi kasir lokal untuk membantu pencatatan produk dan transaksi usaha. Versi Basic yang direncanakan dapat digunakan tanpa akun dan tanpa layanan backend.

## 2. Tanggung jawab pengguna
Pengguna bertanggung jawab atas ketepatan nama produk, harga, stok, pajak, diskon, dan nominal pembayaran yang dimasukkan. Pengguna bertanggung jawab menyimpan file backup JSON secara aman. File memuat profil toko, kategori, produk, stok, transaksi, snapshot identitas toko pada saat transaksi, rincian struk, dan ambang stok rendah. File tidak dienkripsi oleh aplikasi. Pengguna harus memeriksa isi dan tujuan file sebelum membagikannya.

## 3. Penyimpanan data
Data POS disimpan pada perangkat. Pengembang tidak menjamin pemulihan data yang hilang akibat kerusakan perangkat, penghapusan aplikasi, reset perangkat, atau kegagalan media penyimpanan. Pengguna disarankan menggunakan fitur ekspor backup JSON secara berkala dan memeriksa apakah file dapat dipulihkan.

## 4. Penggunaan aplikasi
Aplikasi tidak menggantikan kewajiban pengguna untuk memenuhi ketentuan perpajakan, pembukuan, perlindungan konsumen, dan ketentuan usaha yang berlaku.

## 5. Ketersediaan
Aplikasi disediakan sebagaimana adanya. Pengembang akan melakukan perbaikan sesuai prioritas, tetapi tidak menjanjikan aplikasi bebas gangguan pada semua kombinasi perangkat.

## 6. Layanan SaaS
Informasi layanan SaaS BERKAH TIGA PUTERI bersifat informatif. Dokumen ini tidak mengaktifkan langganan, pembayaran, atau pembelian fitur.

## 7. Kontak
Alamat email dan alamat korespondensi resmi belum diberikan dan wajib dilengkapi sebelum publikasi.
